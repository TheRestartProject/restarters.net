# Phase F cutover checklist (from the read-only audit, 2026-07-16)

Verbatim findings of the phase-f-audit agent against the nuxt-client branch;
supersedes design §9/§10 details where they conflict. Work items marked
[F2-n] become the execution order. Items marked DECISION need a call before
or during F2 (defaults chosen below, flag in the PR).

## Headline findings

1. [F2-1] The kept §9 iframe/widget views `@vite()`-reference the two entries
   F2 deletes (header_plain.blade.php:38, header_nocookie.blade.php:23,
   footer.blade.php:5) — all four partner widgets (outbound/info, admin/stats,
   party/stats, group/stats) would 500. Edit those three layouts to reference
   only surviving entries BEFORE deleting resources/js|sass.
2. [F2-2] errors/{403,404,500,503}.blade.php include layouts.header (when
   authed) / header_plain + footer — framework-invoked on ANY kept route's
   error. Keep + edit these; layouts/header.blade.php survives only for this.
3. [F2-3] /outbound/info/{type}/{id}/leaf renders StatsShare.vue (Vue 2,
   registered only in resources/js/app.js). Port StatsShare to a minimal
   standalone bundle for the widget surface (or drop the leaf format —
   DECISION; default: port, it's partner-facing).
4. DECISION: /group-tag/stats/{id}/{format?} (§9 KEEP) is ALREADY BROKEN —
   GroupController::statsByGroupTag does not exist (only ever referenced by
   the route, commit 455bf46ec3). Default: drop the route at F2 with a note
   in the PR; implement only if partners actually use it.
5. [F2-4] /user/register/{hash} is a live emailed deep link (generated by
   GroupMembershipController:272, EventAttendanceController:336,
   EventController:214 + legacy) — missing from design §5's redirector list.
   Becomes a redirector to FRONTEND_URL/user/register?invite_hash={hash}.
6. [F2-5] The invite/reset "redirectors" are full legacy controllers needing
   REWRITES: GroupController::confirmInvite:391-420 +
   PartyController::confirmInvite:718-734 (update rows then redirect to
   DELETE routes), confirmCodeInvite ×2 (session-array pattern), and
   UserController::reset:449-502 (full Blade form). Rewrite each as a thin
   redirect into the SPA carrying hash/code; the SPA + /api/v2/invites/claim
   handle the rest.
